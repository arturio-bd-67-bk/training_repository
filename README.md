Для проекта интернет‑магазина я бы выбрал модель GitFlow. Она позволяет чётко разделить стабильный код (ветка main) и разработку новых функций (ветки feature/*). Это особенно важно для магазина: нельзя, чтобы новая фича случайно сломала корзину или оплату. 
Если на сайте появится критическая ошибка, её можно быстро исправить в отдельной ветке hotfix и сразу применить к стабильной версии, не затрагивая текущую разработку.
